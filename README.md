# FirebaseApp

## Descrição
Este projeto é um aplicativo Android desenvolvido em Kotlin que demonstra a integração com Firebase para gerenciar mensagens, utilizando dados de sensor de luz e localização (latitude, longitude e endereço).
## Funcionalidades
* Adicionar mensagens com título.
* Capturar o valor do sensor de luz.
* Obter a localização (latitude e longitude) do usuário.
* Obter o endereço a partir da localização usando a API Nominatim.
* Armazenar mensagens no Firebase Firestore associadas a usuários autenticados.
* Autenticação de usuário com Firebase Authentication.
## Tecnologias Utilizadas
* Kotlin
* Android SDK
* Firebase Authentication
* Firebase Firestore
* Google Play Services (Fused Location Provider)
* OkHttp (para a API Nominatim)
* View Binding
## Pré-requisitos
* Android Studio instalado.
* Android SDK configurado.
* Uma conta no Firebase.
